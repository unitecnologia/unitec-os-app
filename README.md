# Unitec OS App

App Flutter de Ordens de Serviço (Android / iOS).

Projeto independente do ERP. Por enquanto: telas visuais + dados mock.

## Telas

- Login
- Minhas OS
- Detalhe da OS
- Nova OS

## Executar

```bash
cd C:\Projetos\unitec-os-app
flutter pub get
flutter run
```

Emulador Android ou iOS precisa estar aberto (ou escolha o device no `flutter devices`).
